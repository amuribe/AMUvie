# AMUvie

AMUvie is a full-stack movie-tracking application. Visitors can browse and search the public movie catalogue, while authenticated users can manage personal to-watch and completed lists.

## Features

- Public movie catalogue
- Movie search and genre filtering
- Detailed movie pages
- User authentication
- Prioritized to-watch list
- Completed viewing history
- Movie ratings and watch counts
- Personal viewing statistics
- Responsive error and status feedback

## Technology

### Frontend

- React
- TypeScript
- React Router
- Vite
- Fetch API

### Backend

- PHP
- MySQL
- PDO
- REST-style JSON API
- API-key authentication
